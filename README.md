# Stack Check – Web Technologies Quiz

Responsive quiz app (HTML, CSS, JavaScript, Tailwind CSS) for CSC336 Assignment 2.

Features: 5 random questions per round from a pool of 10, shuffled options, 20-second countdown,
multi-colored segmented progress bar, correct/wrong highlighting, dark/light mode, PDF result download.

## Run
Open `index.html` in any browser. No build step and no internet needed.

## Files
- `index.html` – page shell and Tailwind setup
- `style.css` – colors, segmented bar, answer states
- `app.js` – quiz logic, timer, PDF writer, theme toggle
- `vendor/tailwind.js` – local Tailwind build
